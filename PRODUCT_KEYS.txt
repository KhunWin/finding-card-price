================================================================================
                            KEY USAGE NOTES
================================================================================

1. Each key can only be used ONCE per installation
2. ⏰ Keys are valid for ONE YEAR from activation date
3. Once a key is activated, it's stored locally with expiration timestamp
4. Keys are case-insensitive (SCRP-A1B2... = scrp-a1b2...)
5. Expired keys will no longer grant access to features

KEY TYPES:
----------
• SCRAPING ONLY (SCRP-): 
  - Allows "Start Scraping" button
  - Upload button will be DISABLED
  - User will be prompted to enter Full Access key for Upload

• FULL ACCESS (FULL-):
  - Allows BOTH "Start Scraping" AND "Upload" buttons
  - Complete access to all features
  - Recommended for power users

DISTRIBUTION:
-------------
- Distribute keys carefully to authorized users only
- Keep a record of which keys are given to which users
- Keys cannot be deactivated once used (one-time use)
- Track activation dates to manage renewals
